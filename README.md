# Hi, I'm Rakib Ul Banna

**Backend Engineer | Node.js & Go | Building scalable microservices and distributed systems**

I build backend systems that handle real traffic, APIs processing thousands of requests, real-time systems with sub-second latency, and AI-powered features that work in production. My focus is on clean architecture, Domain-Driven Design, and building reliable microservices that scale.


## What I Do

I specialize in **backend development** with Node.js/NestJS and Go, building production microservices with a focus on performance, reliability, and maintainability. I've built systems handling 5,000+ concurrent users, reduced query latency by 40%, and doubled throughput on critical paths using Redis caching and async processing.

I work extensively with **microservices architecture**, **Domain-Driven Design**, and **modular monoliths**, designing systems that are maintainable, testable, and ready to scale. I integrate **message queues (RabbitMQ)** for event-driven architectures and **gRPC** for high-performance service communication.

I also have hands-on experience with **AI/LLM integration**, building RAG pipelines with PostgreSQL + pgvector for semantic search and implementing real-time AI streaming with sub-2-second latency via WebSockets.

Full-stack capability with **Next.js/React** when the project requires it.
